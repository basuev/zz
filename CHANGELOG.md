# Changelog

All notable user-visible changes will be documented here. The project follows Semantic Versioning before and after 1.0, with minor versions allowed to contain breaking changes while the major version is zero.

## Unreleased

### Added

- Modal prompt editing with transactional accept and cancel.
- Local autosave, crash recovery, and workspace/global prompt history.
- Fuzzy workspace context search with file preview and line-range references.
- Vim motions and text objects, shell editing keys, and macOS editing shortcuts.
- PTY integration checks and steady-state performance budgets.
