# Support

Use GitHub Issues for reproducible bugs and focused feature requests.

Before reporting a terminal-input problem, include:

- `zz` version or commit;
- operating system and version;
- terminal and version;
- shell;
- keyboard layout;
- the smallest sequence of keys that reproduces the problem.

Do not paste private prompts, secrets, or proprietary source code. Replace sensitive text and paths with a minimal public fixture.

Questions about an unverified coding-agent integration should describe how that tool invokes its external editor and how it handles the editor's exit status and output file.
