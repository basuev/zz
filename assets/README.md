# Project media

- `demo.tape` is the reproducible VHS source for the README terminal demo.
- `demo.gif` is generated from `demo.tape` and should show a complete prompt workflow.
- `social-preview.png` is the 1280x640 GitHub social preview.

Regenerate the assets from the repository root:

```sh
vhs assets/demo.tape
scripts/social-preview.sh
```
